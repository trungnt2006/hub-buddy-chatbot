## B4. Domain
- `Message`: frozen dataclass `role: str` (only `"human"` or `"ai"`), `content: str` (non-empty). Wrong ⇒ `ValueError`.
- `trim_history(messages: list[Message], limit: int) -> list[Message]`: returns the LAST `limit` messages, preserving order; `limit <= 0` ⇒ `ValueError`; empty list ⇒ empty; fewer than `limit` ⇒ return all; does not modify the input list.
- `errors.py`: `ApiKeyMissing`, `InvalidApiKey`, `InvalidMessage`, `InvalidSession`, `UpstreamError(status: int, message: str)`; all inherit `ChatbotError(Exception)`.
- Ports (abstract classes `abc.ABC`):
  - `MemoryRepository`: `get(session_id: str) -> list[Message]`, `append(session_id: str, messages: list[Message]) -> None`, `reset(session_id: str) -> None`.
  - `ChatModel`: `reply(system_prompt: str, history: list[Message], user_text: str) -> str`.
  - `ApiKeyStore`: `is_configured() -> bool`, `get() -> str`, `save(api_key: str) -> None`.

## B5. Application (use cases, one function per file)
- `validate_session_id(session_id) -> str`: matches `^[A-Za-z0-9-]{8,64}$`, otherwise `InvalidSession`.
- `validate_message(text) -> str`: trims leading and trailing whitespace; empty ⇒ `InvalidMessage`; longer than 4000 characters ⇒ `InvalidMessage`.
- `validate_api_key(api_key) -> str`: trims whitespace; length 20 to 200; only printable ASCII characters, NO whitespace inside; wrong ⇒ `InvalidApiKey`. Do NOT check the vendor prefix.
- `get_setup_status(store) -> dict`: `{"configured": store.is_configured()}`.
- `configure_api_key(store, api_key) -> None`: `store.save(validate_api_key(api_key))`.
- `send_message(repo, model, store, system_prompt, max_messages, session_id, text) -> str`:
  1. `sid = validate_session_id(...)`, `msg = validate_message(...)`.
  2. `store.is_configured()` false ⇒ `ApiKeyMissing`.
  3. `history = trim_history(repo.get(sid), max_messages)` (if empty, skip trimming).
  4. `reply = model.reply(system_prompt, history, msg)`.
  5. `repo.append(sid, [Message("human", msg), Message("ai", reply)])` ONLY after `reply` exists; a model error ⇒ write NOTHING to memory.
  6. return `reply`.
- `reset_conversation(repo, session_id) -> None`: validate `session_id`, then `repo.reset(sid)`; resetting a non-existent session is a silent success.

## B6. Infrastructure
- `atomic_write_text(path, text)`: writes to a temp file in the same directory then `os.replace`; creates the parent directory if missing; on error ⇒ delete the temp file, rethrow the error.
- `atomic_write_json(path, data)`: `json.dumps(ensure_ascii=False, indent=2)` then `atomic_write_text`.
- `JsonMemoryRepository(path)`: uses `threading.Lock`; file format `{"<session_id>": [{"role": "human", "content": "..."}]}`; missing file ⇒ empty; corrupt file (invalid JSON) ⇒ rename to `memory.json.corrupt-<timestamp>` then start empty, MUST NOT crash; `append` reads then writes atomically within the same lock; stores ALL messages (trimming happens only when reading for the model).
- `load_system_prompt(path) -> str`: reads UTF-8; missing file ⇒ returns a short Vietnamese default, MUST NOT crash; empty file ⇒ also the default.
- `EnvApiKeyStore(env_path)`: `is_configured()` is true exactly when `get()` is non-empty; `get()` reads `OPENAI_API_KEY` from the `.env` file (and from `os.environ` if the file is missing); `save(key)` rewrites the `.env` file keeping the other lines intact, replacing or appending exactly one line `OPENAI_API_KEY=<key>`, writes atomically, updates `os.environ`; write error ⇒ rethrow, MUST NOT leave a half-written file.
- `mask_secret(value) -> str`: returns `"****"` plus the last 4 characters when the length is 12 or more; otherwise `"****"`; used for logs, MUST NEVER write the real key.
- `LangChainChatModel(settings, store)`: each `reply` builds `ChatPromptTemplate.from_messages([("system", system_prompt), MessagesPlaceholder("history"), ("human", "{input}")])`, attaches `ChatOpenAI(model=settings.openai_model, temperature=settings.openai_temperature, timeout=settings.openai_timeout, api_key=store.get())`, converts `Message` to `HumanMessage`/`AIMessage`, returns `.content`; OpenAI error ⇒ `UpstreamError(*map_openai_error(exc))`; the key is read AGAIN on every turn so that no restart is needed after `/api/setup`.
- `map_openai_error(exc) -> tuple[int, str]`: `AuthenticationError`→401 "Khóa API không đúng, nhập lại"; `RateLimitError` (HTTP 429)→503 "Hệ thống đang quá tải, thử lại sau"; `APITimeoutError`→504 "Mô hình trả lời quá lâu"; `APIConnectionError`→502 "Không kết nối được dịch vụ mô hình"; otherwise→500 "Có lỗi không mong đợi".

Algorithm of `load_settings(env_path: Path) -> Settings`: IF `env_path.exists()` then `raw := dotenv_values(env_path, encoding="utf-8-sig")`, ELSE `raw := {}` empty; `host := _text(raw, "HOST", DEFAULT_HOST)`; IF `host` is not in `("127.0.0.1", "localhost")` then raise `SettingsError` naming HOST; RETURN `Settings(...)` with the nine fields, in which the API key goes through `_text` with default `""` and is NOT format-validated, the three integer keys go through `_integer`, one float key goes through `_number`, and the three remaining string keys go through `_text` with their default constants. Algorithm of `_text(raw, key, default)`: IF `raw.get(key)` is `None` return `default`; strip whitespace at both ends; IF still empty return `default`, ELSE return the stripped string. Algorithm of `_number(raw, key, default, low, high)`: build the message once; `text := _text(raw, key, None)`; IF `text` is `None` return `default`; TRY `float(text)`, EXCEPT `ValueError` then raise `SettingsError` with the message already built and `from None`; IF not finite by `math.isfinite` OR less than `low` OR greater than `high` then raise `SettingsError`; ELSE return the number. Algorithm of `_integer(raw, key, default, low, high)`: same as `_number` but BEFORE casting, IF `text.lstrip("+-")` is not all digits then raise `SettingsError`, ensuring `2610.5` is not silently truncated to `2610`. The code below is the runnable version, 73 lines:

```python
import math
from pathlib import Path

from dotenv import dotenv_values

from src.chatbot.config.settings import (
    DEFAULT_HOST, DEFAULT_MAX_MESSAGES, DEFAULT_MEMORY_FILE,
    DEFAULT_OPENAI_MODEL, DEFAULT_OPENAI_TEMPERATURE,
    DEFAULT_OPENAI_TIMEOUT, DEFAULT_PORT,
    DEFAULT_SYSTEM_PROMPT_FILE, Settings,
)
from src.chatbot.config.settings_error import SettingsError

ALLOWED_HOSTS = ("127.0.0.1", "localhost")


def load_settings(env_path: Path) -> Settings:
    """PRE: env_path là đường dẫn tệp .env, được phép không tồn tại.
    POST: trả về Settings đóng băng đúng chín trường ở B3.
    INV: không ghi os.environ; thông điệp lỗi không chứa giá trị khóa API."""
    raw = dotenv_values(env_path, encoding="utf-8-sig") if env_path.exists() else {}
    host = _text(raw, "HOST", DEFAULT_HOST)
    if host not in ALLOWED_HOSTS:
        raise SettingsError("HOST phải là 127.0.0.1 hoặc localhost, không được dùng địa chỉ khác")
    return Settings(
        openai_api_key=_text(raw, "OPENAI_API_KEY", ""),
        openai_model=_text(raw, "OPENAI_MODEL", DEFAULT_OPENAI_MODEL),
        openai_temperature=_number(raw, "OPENAI_TEMPERATURE", DEFAULT_OPENAI_TEMPERATURE, 0.0, 2.0),
        openai_timeout=_integer(raw, "OPENAI_TIMEOUT", DEFAULT_OPENAI_TIMEOUT, 1, 300),
        host=host,
        port=_integer(raw, "PORT", DEFAULT_PORT, 1024, 65535),
        memory_file=_text(raw, "MEMORY_FILE", DEFAULT_MEMORY_FILE),
        max_messages=_integer(raw, "MAX_MESSAGES", DEFAULT_MAX_MESSAGES, 1, 50),
        system_prompt_file=_text(raw, "SYSTEM_PROMPT_FILE", DEFAULT_SYSTEM_PROMPT_FILE),
    )


def _text(raw, key, default):
    """IF thiếu hoặc rỗng sau cắt: RETURN default. ELSE RETURN chuỗi đã cắt."""
    value = raw.get(key)
    if value is None:
        return default
    value = value.strip()
    return value if value else default


def _number(raw, key, default, low, high):
    """Parse số thực trong khoảng; sai ký tự, ngoài khoảng hoặc không hữu hạn đều ném lỗi."""
    message = f"{key} phải là số trong khoảng {low} đến {high}"
    text = _text(raw, key, None)
    if text is None:
        return default
    try:
        number = float(text)
    except ValueError:
        raise SettingsError(message) from None
    if not math.isfinite(number) or not low <= number <= high:
        raise SettingsError(message)
    return number


def _integer(raw, key, default, low, high):
    """Parse số nguyên trong khoảng; chữ, số thực, ngoài khoảng đều ném lỗi."""
    message = f"{key} phải là số nguyên trong khoảng {low} đến {high}"
    text = _text(raw, key, None)
    if text is None:
        return default
    if not text.lstrip("+-").isdigit():
        raise SettingsError(message)
    number = int(text)
    if not low <= number <= high:
        raise SettingsError(message)
    return number
```

## 5.3. `src/chatbot/config/load_settings.py`

```python
# src/chatbot/config/load_settings.py
from pathlib import Path

from dotenv import dotenv_values

from src.chatbot.config.settings import Settings
from src.chatbot.config.settings_error import SettingsError

DEFAULTS = {
    "OPENAI_API_KEY": "",
    "OPENAI_MODEL": "gpt-4o-mini",
    "OPENAI_TEMPERATURE": "0.3",
    "OPENAI_TIMEOUT": "30",
    "HOST": "127.0.0.1",
    "PORT": "2610",
    "MEMORY_FILE": "memory.json",
    "MAX_MESSAGES": "5",
    "SYSTEM_PROMPT_FILE": "system-prompt.txt",
}

ALLOWED_HOSTS = ("127.0.0.1", "localhost")


def _as_text(key: str, raw: str) -> str:
    value = (raw or "").strip()
    if value == "":
        raise SettingsError(f"Khóa {key} không được để trống.")
    return value


def _as_int(key: str, raw: str, low: int, high: int) -> int:
    try:
        value = int(str(raw).strip())
    except (TypeError, ValueError):
        raise SettingsError(
            f"Khóa {key} phải là số nguyên từ {low} đến {high}; "
            f"giá trị đọc được không phải số nguyên."
        ) from None
    if not low <= value <= high:
        raise SettingsError(
            f"Khóa {key} phải nằm trong khoảng {low} đến {high}; nhận được {value}."
        )
    return value


def _as_float(key: str, raw: str, low: float, high: float) -> float:
    try:
        value = float(str(raw).strip())
    except (TypeError, ValueError):
        raise SettingsError(
            f"Khóa {key} phải là số thực từ {low} đến {high}; "
            f"giá trị đọc được không phải số thực."
        ) from None
    if not low <= value <= high:
        raise SettingsError(
            f"Khóa {key} phải nằm trong khoảng {low} đến {high}; nhận được {value}."
        )
    return value


def _read_env(env_path) -> dict:
    path = Path(env_path)
    if not path.is_file():
        return {}
    values = dotenv_values(path, encoding="utf-8-sig")
    return {k: v for k, v in values.items() if k}


def load_settings(env_path=".env") -> Settings:
    raw = _read_env(env_path)
    host = _as_text("HOST", raw.get("HOST", DEFAULTS["HOST"])).lower()
    if host not in ALLOWED_HOSTS:
        raise SettingsError(
            f"Khóa HOST chỉ chấp nhận 127.0.0.1 hoặc localhost; nhận được {host}."
        )
    return Settings(
        openai_api_key=(raw.get("OPENAI_API_KEY", "") or "").strip(),
        openai_model=_as_text("OPENAI_MODEL", raw.get("OPENAI_MODEL", DEFAULTS["OPENAI_MODEL"])),
        openai_temperature=_as_float("OPENAI_TEMPERATURE", raw.get("OPENAI_TEMPERATURE", DEFAULTS["OPENAI_TEMPERATURE"]), 0.0, 2.0),
        openai_timeout=_as_int("OPENAI_TIMEOUT", raw.get("OPENAI_TIMEOUT", DEFAULTS["OPENAI_TIMEOUT"]), 1, 300),
        host=host,
        port=_as_int("PORT", raw.get("PORT", DEFAULTS["PORT"]), 1024, 65535),
        memory_file=_as_text("MEMORY_FILE", raw.get("MEMORY_FILE", DEFAULTS["MEMORY_FILE"])),
        max_messages=_as_int("MAX_MESSAGES", raw.get("MAX_MESSAGES", DEFAULTS["MAX_MESSAGES"]), 1, 50),
        system_prompt_file=_as_text("SYSTEM_PROMPT_FILE", raw.get("SYSTEM_PROMPT_FILE", DEFAULTS["SYSTEM_PROMPT_FILE"])),
    )
```

# 6. Notices:

- Do NOT modify `os.environ` in `load_settings`: process memory must be left to P5's `EnvApiKeyStore`, otherwise `/api/setup` cannot update the key without a restart.
- Do NOT use `load_dotenv()` because this function writes into `os.environ` by itself and breaks the first-time key entry flow.
- Do NOT put an API key value into any error message: the learner pastes a real key into the box, and the error message gets printed to the command-line window.
- Do NOT validate the provider prefix in `load_settings`: a key that is formally valid but rejected will be caught at P5 with a 401, not here.
- Do NOT allow `HOST=0.0.0.0`: the platform is a personal machine, and opening the network is a hole that lets the key be read from other machines.
- Do NOT loosen the `PORT` range below 1024: system ports require privileges, and the learner would have to run with administrator rights.
- Do NOT use `from __future__ import annotations` together with `dict[str, str]` when types are not yet declared: keep the simple `-> dict` signature so that no error is produced on older Python versions.
- Do NOT catch broad `Exception` in `_as_int` / `_as_float`: catch only `TypeError` and `ValueError`, otherwise programming errors get swallowed.
- Do NOT use `except ...:` and then re-raise the same type while losing the context: always `raise ... from None` when the message already says enough.
- Do NOT print `DEFAULTS` or the whole `raw` dict to the log: that would expose `OPENAI_API_KEY` once the learner has entered a key and restarted.
- Do NOT omit `encoding="utf-8-sig"` in `dotenv_values`: the `.env` file written by P5 on Windows may carry a BOM; without this argument the first key name gets glued to an invisible character and every default value is ignored.
- Do NOT omit `.strip()` in `_as_int` / `_as_float` / `_as_text`: values in `.env` often have extra spaces around the equals sign, and without trimming `int()` fails.
- Do NOT add `.env` to `.gitignore` after P1 has already created it: re-check with the secret-scan command before reporting.
- Do NOT create extra helper files outside the directory tree in B2: the `_as_*` functions must live in `load_settings.py`.
- Do NOT exceed 100 lines in any file: if `test_load_settings.py` is longer, use `@pytest.mark.parametrize` to compress it.
- Do NOT drop the "no key leak" and "does not modify `os.environ`" test groups: these are the two cases that protect the key entry flow of P5 and P6.
- Do NOT start the server inside the opencode shell: P2 only runs `py -m pytest`, not `py run.py`.
- Do NOT use `python3`, `curl`, `sudo`, or bash commands: the platform is Windows 11 with PowerShell and `py`.
- Do NOT report "done" while the 100-line rule command still prints file names.
- Do NOT write a key string with a provider prefix into any file: every key in the test must be `TEST_KEY_` followed by 20 x letters.
- Do NOT write unaccented Vietnamese in error messages and in the report: the learner reads the notification right there in the command-line window.


Binding rule B24: every prompt in this project must explicitly state how to resume work if opencode stops midway. The resume procedure is fixed: re-paste the most recent prompt unchanged into a fresh session, then re-establish context by reading the files and the last checkpoint before making any new edits; a checkpoint is defined as the state where the full test suite passes, so resumption always targets the last green checkpoint rather than an arbitrary half-finished edit. If the suite cannot run, the checkpoint is the most recent file save that preserves prior passing behavior, and the resuming session must verify it before proceeding. Never re-explain requirements or invent missing steps on resume.
