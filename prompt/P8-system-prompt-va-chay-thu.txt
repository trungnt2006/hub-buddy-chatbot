## 3.BLUEPRINT. Blueprint v4 (verbatim, shared by all 10 prompts)
# BLUEPRINT v4: web chatbot, 10 prompts, DDD, TDD, MUI, first-time API key entry on the page

User lock-in 2026-10-07: the prompt IS the blueprint; an AI that reads all 10 prompts (P0 through P9) can build the chatbot; each prompt is at least 5,000 words, written in formal specification style, covering every case; the first thing to do when the chatbot runs for the first time is TO ASK FOR THE API KEY, send it to the server, the server stores it, and then it runs.

## B1. Goal and first-run flow
- Platform: Windows 11, PowerShell, Python invoked via `py`, coding assistant is opencode, responding model is `gpt-4o-mini` via the OpenAI API (external API).
- First-run flow:
  1. The learner runs `py run.py`; the server starts at `http://127.0.0.1:2610` WHEN THERE IS NO API KEY YET (must not crash).
  2. The browser opens the page; `main.js` calls `GET /api/setup/status`.
  3. It returns `{"configured": false}` ⇒ show the MUI dialog "Nhập khóa API" (password field + Save button).
  4. The learner pastes the key, clicks Save ⇒ `POST /api/setup` with `{"api_key": "<key>"}`.
  5. The server validates the key format, writes it into the `.env` file (line `OPENAI_API_KEY=`) atomically, updates the process memory, returns `{"ok": true}`; it must NEVER return the key.
  6. The page closes the dialog and shows the chat frame; chat runs immediately, no restart needed.
  7. Subsequent runs: `status` returns `{"configured": true}` ⇒ go straight to the chat frame.
- The key lives only in `.env`; not in logs, not in `memory.json`, not in responses, not in errors.

## B4. Domain
- `Message`: frozen dataclass `role: str` (only `"human"` or `"ai"`), `content: str` (non-empty). Wrong ⇒ `ValueError`.
- `trim_history(messages: list[Message], limit: int) -> list[Message]`: returns the LAST `limit` messages, preserving order; `limit <= 0` ⇒ `ValueError`; empty list ⇒ empty; fewer than `limit` ⇒ return all; does not modify the input list.
- `errors.py`: `ApiKeyMissing`, `InvalidApiKey`, `InvalidMessage`, `InvalidSession`, `UpstreamError(status: int, message: str)`; all inherit `ChatbotError(Exception)`.
- Ports (abstract classes `abc.ABC`):
  - `MemoryRepository`: `get(session_id: str) -> list[Message]`, `append(session_id: str, messages: list[Message]) -> None`, `reset(session_id: str) -> None`.
  - `ChatModel`: `reply(system_prompt: str, history: list[Message], user_text: str) -> str`.
  - `ApiKeyStore`: `is_configured() -> bool`, `get() -> str`, `save(api_key: str) -> None`.

## B5. Application (use cases, one function per file)
- `validate_session_id(session_id) -> str`: matches `^[A-Za-z0-9-]{8,64}$`, otherwise `InvalidSession`.
- `validate_message(text) -> str`: trims leading and trailing whitespace; empty ⇒ `InvalidMessage`; longer than 4000 characters ⇒ `InvalidMessage`.
- `validate_api_key(api_key) -> str`: trims whitespace; length 20 to 200; only printable ASCII characters, NO whitespace inside; wrong ⇒ `InvalidApiKey`. Do NOT check the vendor prefix.
- `get_setup_status(store) -> dict`: `{"configured": store.is_configured()}`.
- `configure_api_key(store, api_key) -> None`: `store.save(validate_api_key(api_key))`.
- `send_message(repo, model, store, system_prompt, max_messages, session_id, text) -> str`:
  1. `sid = validate_session_id(...)`, `msg = validate_message(...)`.
  2. `store.is_configured()` false ⇒ `ApiKeyMissing`.
  3. `history = trim_history(repo.get(sid), max_messages)` (if empty, skip trimming).
  4. `reply = model.reply(system_prompt, history, msg)`.
  5. `repo.append(sid, [Message("human", msg), Message("ai", reply)])` ONLY after `reply` exists; a model error ⇒ write NOTHING to memory.
  6. return `reply`.
- `reset_conversation(repo, session_id) -> None`: validate `session_id`, then `repo.reset(sid)`; resetting a non-existent session is a silent success.

## B6. Infrastructure
- `atomic_write_text(path, text)`: writes to a temp file in the same directory then `os.replace`; creates the parent directory if missing; on error ⇒ delete the temp file, rethrow the error.
- `atomic_write_json(path, data)`: `json.dumps(ensure_ascii=False, indent=2)` then `atomic_write_text`.
- `JsonMemoryRepository(path)`: uses `threading.Lock`; file format `{"<session_id>": [{"role": "human", "content": "..."}]}`; missing file ⇒ empty; corrupt file (invalid JSON) ⇒ rename to `memory.json.corrupt-<timestamp>` then start empty, MUST NOT crash; `append` reads then writes atomically within the same lock; stores ALL messages (trimming happens only when reading for the model).
- `load_system_prompt(path) -> str`: reads UTF-8; missing file ⇒ returns a short Vietnamese default, MUST NOT crash; empty file ⇒ also the default.
- `EnvApiKeyStore(env_path)`: `is_configured()` is true exactly when `get()` is non-empty; `get()` reads `OPENAI_API_KEY` from the `.env` file (and from `os.environ` if the file is missing); `save(key)` rewrites the `.env` file keeping the other lines intact, replacing or appending exactly one line `OPENAI_API_KEY=<key>`, writes atomically, updates `os.environ`; write error ⇒ rethrow, MUST NOT leave a half-written file.
- `mask_secret(value) -> str`: returns `"****"` plus the last 4 characters when the length is 12 or more; otherwise `"****"`; used for logs, MUST NEVER write the real key.
- `LangChainChatModel(settings, store)`: each `reply` builds `ChatPromptTemplate.from_messages([("system", system_prompt), MessagesPlaceholder("history"), ("human", "{input}")])`, attaches `ChatOpenAI(model=settings.openai_model, temperature=settings.openai_temperature, timeout=settings.openai_timeout, api_key=store.get())`, converts `Message` to `HumanMessage`/`AIMessage`, returns `.content`; OpenAI error ⇒ `UpstreamError(*map_openai_error(exc))`; the key is read AGAIN on every turn so that no restart is needed after `/api/setup`.
- `map_openai_error(exc) -> tuple[int, str]`: `AuthenticationError`→401 "Khóa API không đúng, nhập lại"; `RateLimitError` (HTTP 429)→503 "Hệ thống đang quá tải, thử lại sau"; `APITimeoutError`→504 "Mô hình trả lời quá lâu"; `APIConnectionError`→502 "Không kết nối được dịch vụ mô hình"; otherwise→500 "Có lỗi không mong đợi".

## B7. Interface (Flask)

}


class ScriptedModel:
    """Mô hình giả: trả lời theo kịch bản và ghi lại mọi lời gọi."""

    def __init__(self, replies):
        self.replies = list(replies)
        self.calls = []

    def reply(self, system_prompt, history, user_text):
        self.calls.append((system_prompt, list(history), user_text))
        return self.replies.pop(0)


def build_app(tmp_path, replies):
    """Dựng ứng dụng; lần dựng sau vẫn thấy khóa đã lưu trong tệp .env."""
    env_path = tmp_path / ".env"
    if not env_path.exists():
        env_path.write_text("OPENAI_MODEL=fake-model\n", encoding="utf-8")
    model = ScriptedModel(replies)
    app = create_app(
        settings=Settings(**FIELDS),
        repo=JsonMemoryRepository(tmp_path / "memory.json"),
        model=model,
        store=EnvApiKeyStore(env_path),
        system_prompt_loader=lambda *a, **k: "bản kiểm thử",
    )
    return app, model

|---|---|---|---|

| `POST /api/setup`, the key is empty or all whitespace | `validate_api_key` | `400` | `invalid_api_key` |
| `POST /api/setup`, length outside the range of 20 to 200 | `validate_api_key` | `400` | `invalid_api_key` |
| `POST /api/setup`, contains characters outside printable ASCII or contains inner whitespace | `validate_api_key` | `400` | `invalid_api_key` |
| `POST /api/setup`, the key is well-formed | `EnvApiKeyStore.save` writes atomically | `{"ok": true}` | `500 save_failed` when the file cannot be written |
| `POST /api/setup` from another machine | `request.remote_addr` is not in `{"127.0.0.1", "::1"}` | `403` | `forbidden` |
| `POST /api/setup` missing `Content-Type: application/json` | `require_json` | `415` | `unsupported_media_type` |

| The file exists and has content | the UTF-8 read succeeds | return the content verbatim | none |
| The file exists but is empty or only whitespace | `len(text.strip()) == 0` | return the default string in accented Vietnamese | none |
| The file does not exist | `is_file()` returns `False` | return the default string | none |
| The file has a wrong encoding and the UTF-8 read fails | the decoding error is caught | return the default string | none |
| The file has a byte order mark | the UTF-8 read still succeeds | the content is still returned; the first heading may come with a stray character | the file should be saved without a byte order mark |
| The learner edits the file and then asks right away | `run.py` calls `load_system_prompt` only once at startup | the old content is still used | none |
| A restart happens after the edit | `load_system_prompt` is called again | the new content is used | none |
| The file lacks one of the seven headings | the test `test_system_prompt_file_has_required_sections` | the test goes red and names the missing item | fix the file; do not loosen the test condition |
| The file exceeds 120 characters per line | the test `test_system_prompt_file_lines_are_short` | the test goes red | fix the file |
| The file contains paths, network addresses or configuration key names | the test `test_system_prompt_file_has_no_secret_or_path` | the test goes red | remove them from the file; this is a violation of INV-P8-6 |

Table 4. Decisions for `memory.json`

| Input condition | Check | Output result | Exception |
|---|---|---|---|
| The file is missing | `is_file()` returns `False` | treat it as empty; the next write creates the file | none |
| The directory containing the file is missing | `atomic_write_text` creates the parent directory | create the directory and then write | none |
| The file is corrupt, the JSON is invalid | `json.loads` throws | rename it to `memory.json.corrupt-<timestamp>` and start empty | the JSON error is swallowed deliberately |
| Concurrent writes from multiple requests | `threading.Lock` is held across the whole read then write | no message is lost | if the lock is skipped, messages are lost, which violates INV |
| A reset of a session that does not exist | the session key is not in the file | succeed silently | none |
| A message has Vietnamese diacritics and emoji | `atomic_write_json` uses `ensure_ascii=False` | reading it back with `-Encoding UTF8` shows the diacritics correctly | none |
| A string contains the API key | match it against the value in `.env` without printing the value | a leaked key is detected and the report stops | none |
| A message contains special HTML characters | the content is a string child of a React element | it is displayed verbatim, not executed | none |
| The history exceeds `MAX_MESSAGES` | trim it only when it is read for the model | the file still keeps every message | none; this matches the decision at B6 |

# 4. Format:

## 4.0 Terminology, defined once for all of P8

| term | Vietnamese meaning |
|---|---|
| opencode | coding assistant that runs in a command-line window, reads the task description and then generates files |
| API | programming interface for a program to call an external service, here the model service |
| endpoint | a specific URL path that the API listens on, e.g. `/api/chat` |
| venv | virtual Python environment, the `.venv` directory, isolating installed packages from the system |
| pytest | automated test-running tool for Python |
| DDD | theory of designing around the business domain, split into interface, application, domain, infrastructure layers |

## 5.2 `src/chatbot/infrastructure/load_system_prompt.py`

```python
"""Nap system-prompt.txt theo UTF-8; thieu tep hoac tep rong thi dung mac dinh."""

from pathlib import Path

DEFAULT_SYSTEM_PROMPT = (
    "Ban la tro ly hoc tap HUB-Buddy. "
    "Tra loi bang tieng Viet co dau, ngan gon, dung vai tro tro ly."
)


def load_system_prompt(path: str) -> str:
    """PRE: path la chuoi duong dan tep. POST: tra ve chuoi khong rong."""
    target = Path(path)
    try:
        text = target.read_text(encoding="utf-8")
    except OSError:
        return DEFAULT_SYSTEM_PROMPT
    except UnicodeDecodeError:
        return DEFAULT_SYSTEM_PROMPT
    cleaned = text.replace("﻿", "").strip()
    if not cleaned:
        return DEFAULT_SYSTEM_PROMPT
    return cleaned
```

# 6. Notices:

- Do NOT paste the API key into this conversation with opencode; reason: the key will remain in the work-session history.
- Do NOT paste the key into `.env.example`, `AGENTS.md`, `system-prompt.txt`, `memory.json`; reason: these files are easily copied.
- Do NOT print the key to the PowerShell window or into the log; use `mask_secret` returning `****` plus the last 4 characters; reason: avoid leaking through screenshots.
- Do NOT run `py run.py` directly in opencode's shell; use `Start-Process`; reason: the server occupies the process loop.
- Do NOT use bash commands, do NOT use `sudo`, do NOT use `source`, do NOT use `curl`; reason: the blueprint uses only PowerShell and `Invoke-RestMethod`.
- Do NOT use `python3`; on Windows 11 the command is `py`; reason: `python3` may not exist.
- Do NOT create files outside the B2 folder tree, do NOT create `AGENTS.local.md`, do NOT create a `scripts/` folder; reason: the folder tree is the contract among 10 prompts.
- Do NOT use JSX or Babel in `static/js`; reason: the blueprint forbids it, you must use `React.createElement` with global variables.
- Do NOT use `innerHTML` or `dangerouslySetInnerHTML` in any file under `static/`; reason: the `<script>` case must be shown verbatim.
- Do NOT write a sample key string beginning with the provider's prefix; in tests use only `TEST_KEY_` plus 20 x's; reason: avoid letting a real key fall into source code.
- Do NOT change the decision to read `system-prompt.txt` on every startup; reason: reading every turn increases file operations and makes answers unstable.
- Do NOT let `/api/chat` receive history from the client; reason: the client could fake roles and corrupt memory.
- Do NOT use a fake key to claim the real flow ran; when saving `TEST_KEY_xxxxxxxxxxxxxxxxxxxx` and receiving 401 that is the CORRECT RESULT; reason: prove error mapping, not prove the model works.
- Do NOT delete `memory.json` when corruption occurs; rename it to `memory.json.corrupt-<timestamp>`; reason: keep traces for investigation.
- Do NOT reinitialize the application while two requests are running; reason: contention on the memory-file write lock.
- Do NOT open two tabs and enter different keys in the same `session_id`; reason: memory is per session, easy to misunderstand.
- Do NOT run `py -m pytest -q` before activating `.\.venv\Scripts\Activate.ps1`; reason: `langchain` and `flask` may be missing.
- Do NOT write `system-prompt.txt` with a BOM; the loader already filters `ufeff` but the original file should still be clean; reason: BOM causes errors in other tools.
- Do NOT conclude "done" before running the 100-line check and the secret scan; reason: these two commands are machine evidence, not a promise.
- Do NOT print the whole raw response content of the model service into the log; reason: it may contain user data.
