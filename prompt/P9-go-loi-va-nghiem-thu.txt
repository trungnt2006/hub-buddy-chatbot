## 3b. Short glossary

opencode: a programming assistant running in the command-line window, reading prompts and editing files based on instructions.
API: application programming interface, here the external model service that the server calls to obtain answers.
endpoint: a specific path on the server that receives requests and returns results, e.g. `/api/chat`.
venv: a dedicated virtual Python environment for the project, created with `py -m venv .venv` and activated with `.\.venv\Scripts\Activate.ps1`.
pytest: the automated test runner for Python, invoked with `py -m pytest -q`.
DDD: an architecture style that layers by business domain, here interface, application, domain and infrastructure with one-way dependency arrows.
TDD: the process of writing tests before writing code, so that code is only produced to make tests green.
MUI: a React UI component library provided by Material, here loaded from the CDN and used through the global variable `MaterialUI`.
formal spec: a formal specification consisting of precondition, postcondition and invariant blocks written with numbering so they can be verified by command.
debugging round: a round consisting of reading the raw error, bracketing the layer, fixing minimally, then re-running the entire test suite.
minimal patch: the smallest change that makes one cause of the error disappear, with no unrelated refactoring.
acceptance evidence: a result line observed from a command or a test, used to prove that a case is correct or still has an error.

## B4. Domain
- `Message`: frozen dataclass `role: str` (only `"human"` or `"ai"`), `content: str` (non-empty). Wrong ⇒ `ValueError`.
- `trim_history(messages: list[Message], limit: int) -> list[Message]`: returns the LAST `limit` messages, preserving order; `limit <= 0` ⇒ `ValueError`; empty list ⇒ empty; fewer than `limit` ⇒ return all; does not modify the input list.
- `errors.py`: `ApiKeyMissing`, `InvalidApiKey`, `InvalidMessage`, `InvalidSession`, `UpstreamError(status: int, message: str)`; all inherit `ChatbotError(Exception)`.
- Ports (abstract classes `abc.ABC`):
  - `MemoryRepository`: `get(session_id: str) -> list[Message]`, `append(session_id: str, messages: list[Message]) -> None`, `reset(session_id: str) -> None`.
  - `ChatModel`: `reply(system_prompt: str, history: list[Message], user_text: str) -> str`.
  - `ApiKeyStore`: `is_configured() -> bool`, `get() -> str`, `save(api_key: str) -> None`.

## B5. Application (use cases, one function per file)
- `validate_session_id(session_id) -> str`: matches `^[A-Za-z0-9-]{8,64}$`, otherwise `InvalidSession`.
- `validate_message(text) -> str`: trims leading and trailing whitespace; empty ⇒ `InvalidMessage`; longer than 4000 characters ⇒ `InvalidMessage`.
- `validate_api_key(api_key) -> str`: trims whitespace; length 20 to 200; only printable ASCII characters, NO whitespace inside; wrong ⇒ `InvalidApiKey`. Do NOT check the vendor prefix.
- `get_setup_status(store) -> dict`: `{"configured": store.is_configured()}`.
- `configure_api_key(store, api_key) -> None`: `store.save(validate_api_key(api_key))`.
- `send_message(repo, model, store, system_prompt, max_messages, session_id, text) -> str`:
  1. `sid = validate_session_id(...)`, `msg = validate_message(...)`.
  2. `store.is_configured()` false ⇒ `ApiKeyMissing`.
  3. `history = trim_history(repo.get(sid), max_messages)` (if empty, skip trimming).
  4. `reply = model.reply(system_prompt, history, msg)`.
  5. `repo.append(sid, [Message("human", msg), Message("ai", reply)])` ONLY after `reply` exists; a model error ⇒ write NOTHING to memory.
  6. return `reply`.
- `reset_conversation(repo, session_id) -> None`: validate `session_id`, then `repo.reset(sid)`; resetting a non-existent session is a silent success.

## B6. Infrastructure
- `atomic_write_text(path, text)`: writes to a temp file in the same directory then `os.replace`; creates the parent directory if missing; on error ⇒ delete the temp file, rethrow the error.
- `atomic_write_json(path, data)`: `json.dumps(ensure_ascii=False, indent=2)` then `atomic_write_text`.
- `JsonMemoryRepository(path)`: uses `threading.Lock`; file format `{"<session_id>": [{"role": "human", "content": "..."}]}`; missing file ⇒ empty; corrupt file (invalid JSON) ⇒ rename to `memory.json.corrupt-<timestamp>` then start empty, MUST NOT crash; `append` reads then writes atomically within the same lock; stores ALL messages (trimming happens only when reading for the model).
- `load_system_prompt(path) -> str`: reads UTF-8; missing file ⇒ returns a short Vietnamese default, MUST NOT crash; empty file ⇒ also the default.
- `EnvApiKeyStore(env_path)`: `is_configured()` is true exactly when `get()` is non-empty; `get()` reads `OPENAI_API_KEY` from the `.env` file (and from `os.environ` if the file is missing); `save(key)` rewrites the `.env` file keeping the other lines intact, replacing or appending exactly one line `OPENAI_API_KEY=<key>`, writes atomically, updates `os.environ`; write error ⇒ rethrow, MUST NOT leave a half-written file.
- `mask_secret(value) -> str`: returns `"****"` plus the last 4 characters when the length is 12 or more; otherwise `"****"`; used for logs, MUST NEVER write the real key.
- `LangChainChatModel(settings, store)`: each `reply` builds `ChatPromptTemplate.from_messages([("system", system_prompt), MessagesPlaceholder("history"), ("human", "{input}")])`, attaches `ChatOpenAI(model=settings.openai_model, temperature=settings.openai_temperature, timeout=settings.openai_timeout, api_key=store.get())`, converts `Message` to `HumanMessage`/`AIMessage`, returns `.content`; OpenAI error ⇒ `UpstreamError(*map_openai_error(exc))`; the key is read AGAIN on every turn so that no restart is needed after `/api/setup`.
- `map_openai_error(exc) -> tuple[int, str]`: `AuthenticationError`→401 "Khóa API không đúng, nhập lại"; `RateLimitError` (HTTP 429)→503 "Hệ thống đang quá tải, thử lại sau"; `APITimeoutError`→504 "Mô hình trả lời quá lâu"; `APIConnectionError`→502 "Không kết nối được dịch vụ mô hình"; otherwise→500 "Có lỗi không mong đợi".

import re
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
DOMAIN_DIR = ROOT / "src" / "chatbot" / "domain"
FORBIDDEN = {"flask", "langchain", "openai", "dotenv", "os", "pathlib", "json"}
IMPORT_RE = re.compile(r"^\s*(?:from|import)\s+([A-Za-z0-9_.]+)")


def _root_module(line: str) -> str:
    match = IMPORT_RE.match(line)
    if match is None:
        return ""
    return match.group(1).split(".")[0]


def _violations_text(text: str) -> list[str]:
    found: list[str] = []
    for number, line in enumerate(text.splitlines(), start=1):
        root = _root_module(line)
        if root in FORBIDDEN:
            found.append(f"dòng {number}: {line.strip()}")
    return found


def _domain_files() -> list[Path]:
    if not DOMAIN_DIR.is_dir():
        return []
    return sorted(DOMAIN_DIR.rglob("*.py"))


def _domain_texts() -> list[tuple[str, str]]:
    return [(p.name, p.read_text(encoding="utf-8")) for p in _domain_files()]


def test_root_module_parses_import_lines():
    assert _root_module("import os") == "os"
    assert _root_module("from flask import Flask") == "flask"
    assert _root_module("    from chatbot.domain import message") == "chatbot"
    assert _root_module("x = 1") == ""


def test_violations_text_flags_forbidden_import():
    assert _violations_text("import os\n") == ["dòng 1: import os"]
    assert _violations_text("from pathlib import Path\n") == ["dòng 1: from pathlib import Path"]
    assert _violations_text("from chatbot.domain.message import Message\n") == []
    assert len(_violations_text("import json\nimport os\n")) == 2


def test_domain_purity_no_framework_import():
    offenders: list[str] = []
    for name, text in _domain_texts():
        offenders.extend(f"{name} {item}" for item in _violations_text(text))
    assert offenders == [], "tầng domain cấm import: " + "; ".join(offenders)


def test_domain_purity_no_os_environ_literal():
    offenders = [
        name
        for name, text in _domain_texts()
        if "os.environ" in text or "getenv" in text
    ]
    assert offenders == [], "tầng domain cấm đọc biến môi trường: " + ", ".join(offenders)

## ERR

ERR.1 Symptom: after three full rounds there are still red tests. Cause: the root cause lies outside the nine files allowed to be touched, or an expectation in a test is wrong. Handling: stop, do not guess, print the list of still-red `test_id` together with the full error message, state the suspected layer per table 3d.1, propose two directions for the learner to confirm. Related files: `tests/`, and the source file indicated by table 3d.1.

ERR.2 Symptom: `ImportError: cannot import name X`. Cause: an interface or application file imports a name that has not been defined, or the package path is wrong. Handling: compare the function name with B5 and B7, fix exactly one import line, do not create a new function unless it is genuinely missing. Related files: `src/chatbot/application/*.py`, `src/chatbot/interface/*.py`.

ERR.3 Symptom: `ModuleNotFoundError: No module named 'chatbot'`. Cause: `pytest.ini` lacks `pythonpath = . src`, or the command is run from the wrong root folder. Handling: fix `pytest.ini`, run `py -m pytest -q --collect-only` until enough tests are collected, then actually run them. Related file: `pytest.ini`.

ERR.4 Symptom: `OSError: [WinError 10048]` when running `py run.py`. Cause: port 2610 is busy from an old process. Handling: close the old process with the command in PRE.6, or change `PORT` in `.env` to a value between 1024 and 65535 and run again. Related files: `run.py`, `.env`, `.env.example`.

ERR.5 Symptom: `PermissionError` when saving the key. Cause: the `.env` file has its write permission locked, or it is open in an editor that blocks writing. Handling: close the editor holding the file, remove the read-only attribute, run `test_env_api_key_store_save_failure_raises` again to confirm the error is still raised with the correct type; if the error persists, report it, do not change the exception type. ## 5.1. File `tests/test_domain_purity.py`

```python
import re
from pathlib import Path

DOMAIN_DIR = Path(__file__).resolve().parents[1] / "src" / "chatbot" / "domain"
FORBIDDEN = {"flask", "langchain", "langchain_openai", "openai", "dotenv",
             "os", "pathlib", "json", "threading", "sqlite3"}
IMPORT_RE = re.compile(r"^\s*(?:from\s+([A-Za-z_][\w.]*)|import\s+([A-Za-z_][\w.]*))")
REQUIRED = ("message.py", "trim_history.py", "errors.py",
            "memory_repository.py", "chat_model.py", "api_key_store.py")


def _py_files():
    return sorted(DOMAIN_DIR.rglob("*.py"))


def _root_modules(path):
    found = set()
    for raw in path.read_text(encoding="utf-8").splitlines():
        match = IMPORT_RE.match(raw)
        if match:
            found.add((match.group(1) or match.group(2)).split(".")[0])
    return found


def test_domain_has_files():
    assert _py_files(), f"Không tìm thấy tệp Python nào trong {DOMAIN_DIR}"


def test_domain_imports_are_clean():
    offenders = []
    for path in _py_files():
        bad = sorted(_root_modules(path) & FORBIDDEN)
        if bad:
            offenders.append(f"{path.name}: {bad}")
    assert not offenders, "domain bi import thu vien cam: " + "; ".join(offenders)


def test_domain_never_reads_os_environ():
    for path in _py_files():
        text = path.read_text(encoding="utf-8")
        assert "environ" not in text, f"{path.name} cham vao os.environ"


def test_domain_defines_required_modules():
    names = {path.name for path in _py_files()}
    missing = [item for item in REQUIRED if item not in names]
    assert not missing, "Thieu tep domain: " + ", ".join(missing)
```

## 5.2. File `tests/test_static_rules.py`

```python
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
MAX_LINES = 100
STATIC_DIR = ROOT / "static"
KEY_LINE = "OPENAI_API_KEY="
TEST_MARK = "TEST_KEY_"
FORBIDDEN_IN_STATIC = ("innerHTML", "dangerouslySetInnerHTML")
ENV_KEYS = ["OPENAI_API_KEY", "OPENAI_MODEL", "OPENAI_TEMPERATURE", "OPENAI_TIMEOUT",
            "HOST", "PORT", "MEMORY_FILE", "MAX_MESSAGES", "SYSTEM_PROMPT_FILE"]
REQUIRED_STATIC = ["index.html", "js/session_id.js", "js/api_status.js", "js/api_setup.js",
                   "js/api_chat.js", "js/api_reset.js", "js/message_bubble.js",
                   "js/setup_dialog.js", "js/chat_view.js", "js/send_handler.js",
                   "js/main.js"]


def _source_files():
    files = list((ROOT / "src").rglob("*.py"))
    files += list((ROOT / "tests").rglob("*.py"))
    files += list(STATIC_DIR.rglob("*.js"))
    files += list(STATIC_DIR.rglob("*.html"))
    return sorted(files)


def _text(path):
    return path.read_text(encoding="utf-8")


def _line_count(path):
    return len(_text(path).splitlines())


def test_every_file_under_100_lines():
    over = [f"{p.relative_to(ROOT)}={_line_count(p)}"
            for p in _source_files() if _line_count(p) >= MAX_LINES]
    assert not over, "Tep vuot 100 dong: " + ", ".join(over)


def test_static_files_exist():
    missing = [name for name in REQUIRED_STATIC if not (STATIC_DIR / name).is_file()]
    assert not missing, "Thieu tep giao dien: " + ", ".join(missing)


def test_static_never_builds_raw_html():
    hits = []
    for path in STATIC_DIR.rglob("*.js"):
        for word in FORBIDDEN_IN_STATIC:
            if word in _text(path):
                hits.append(f"{path.name}:{word}")
    assert not hits, "Cam dung HTML tho: " + ", ".join(hits)


def test_env_example_lists_nine_keys():
    text = _text(ROOT / ".env.example")
    missing = [key for key in ENV_KEYS if key not in text]
    assert not missing, "Thieu khoa trong .env.example: " + ", ".join(missing)


def test_env_example_keeps_key_empty():
    for line in _text(ROOT / ".env.example").splitlines():
        if line.startswith(KEY_LINE):
            assert line.strip() == KEY_LINE, ".env.example phai de khoa rong"


def test_gitignore_protects_secret_files():
    text = _text(ROOT / ".gitignore").lower()
    assert ".env" in text, ".gitignore phai chua .env"
    assert "memory.json" in text, ".gitignore phai chua memory.json"


def test_no_secret_leaves_tests():
    offenders = []
    for path in _source_files():
        if "tests" in path.parts:
            continue
        for number, line in enumerate(_text(path).splitlines(), 1):
            if TEST_MARK in line:
                offenders.append(f"{path.name}:{number}")
            if KEY_LINE in line and not line.strip().startswith("#"):
                offenders.append(f"{path.name}:{number}")
    assert not offenders, "Ro khoa ra ngoai test: " + ", ".join(offenders)


def test_memory_json_holds_no_key():
    path = ROOT / "memory.json"
    if not path.is_file():
        return
    assert "api_key" not in _text(path).lower(), "memory.json khong duoc chua khoa"
```
